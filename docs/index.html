What is SSE connecting to?


An existing Ethereum-compatible blockchain—initially Anvil for local tests and eventually a public testnet using native test ETH. Each application VM connects through an Ethereum RPC endpoint; it does not have to run a validator.






What remains before the full marketplace?


Independent wallet custody, monitor bonds and confirmation, transaction-sending agents, real provider workloads, and verifiable cloud-service SLAs. Those are R5/R6/R7 integration tasks, not features of this installer yet.
